> 结论：**已发布版本存在 1 项 S1（新筛选功能不可达）**，建议 v1.1.1 热修后进入下一功能轮。

## 2. 结论与优先级

1. **F-01（S1）**：v1.1.0 新增的时间/来源筛选在默认与最小宽度下都伸出窗口，且滚轮无法到达——
   功能等于不可用。修复成本小（筛选条改两行固定高度），建议立即热修。
2. **F-02（S2）**：「图片另存为」沿用旧的弹窗路径，导致面板隐藏；与上一轮 D-C-01 同因，
   新功能未复用 `SuppressAutoHide` 模式。修复成本极小。
3. **F-03（S2）**：多屏混合 DPI 下的位置恢复用错坐标单位；单屏无感，建议同批修。
4. F-04/F-05/F-06 为打磨项，可并入同一次 v1.1.1。
