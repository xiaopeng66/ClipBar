## 2. 车道

- **A 正确性+并发**（静态，子代理）：ShowPanel 异步化、single-flight、钩子回调、deferred dismiss 代数、几何延迟写、主题 Changed 订阅、设置草稿——竞态/泄漏/重入/异常路径。
- **B UX/布局/一致性**（静态+截图，子代理）：间距/对齐/层级、深浅主题、文案、README/GOAL 漂移、可访问性命名。
- **C 功能矩阵**（实测，主代理）：捕获（文本/HTML/图片/文件）、去重置顶、钉/删/撤销、搜索高亮、类型/来源筛选、右键动作（纯文本/另存为/扩展）、保持打开、暂停捕获、三位置模式、设置全字段、热键、托盘、单实例、便携目录、失败路径（坏 DB/坏设置/只读）。
- **D 压力/竞态**（实测，主代理）：20 轮右键菜单开关、20 轮快速 Esc/热键切换、菜单+保持打开重叠、外点连击、隐藏瞬间再唤起、设置开着时切主题、1000 条历史滚动。
