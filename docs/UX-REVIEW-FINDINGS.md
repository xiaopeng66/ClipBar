## 4. 正面确认（审查通过项）

1. **D-01 绑定/资源零失效**：四个 XAML 全部 `{Binding}`/资源 key/SymbolRegular 图标逐一核对解析成功。
2. **D-07 设置链完整**：10 个设置控件全部有运行时消费方，应用即时生效。
3. **D-04 事件生命周期**：反复打开设置/菜单/弹窗无泄漏（句柄与实例核对）。
4. **D-08 五条唤出路径**（热键/托盘点击/托盘菜单/--show/启动）全部汇入带原因标签的守卫。
5. **C-01/C-05 键盘与焦点还原**：热键→搜索→↑↓→Enter 粘贴→焦点逐字符还原目标输入框（V2 S1 + 本轮复核）。
6. **C-02 菜单 Esc 层级正确**：右键菜单 Esc 只关菜单、面板保留（实测 2→1 窗口）。
7. **C-13 连按热键**：5 次信号仅 1 次显示，不闪烁不重复定位（日志计数）。
8. **A-02 文字对比度**：浅色次级 7.82:1 / 深色次级 13.76:1（第四轮实测方法学，画刷未变）。
9. **E-01~E-10 功能正确性**：385 例测试 + V2 暴力矩阵覆盖，本轮未发现新功能缺陷。
10. **小档图标位渲染正常**（真实环境复核；探针 RTB 空白为组成时序假象，已排除）。

## 5. 维度评分依据摘要

- **A 4.0**：对比度与文字阶梯达标（正面 8）；圆角双体系（D-A-01）、强调色双按钮（D-A-02）、主题跟随缺口（D-A-03）扣分。
- **B 4.0**：4 DIP 网格纪律与左右对称此前已像素级验证；页脚 14、对话框 14/18、7/34 杂值扣分。
- **C 3.5**：键盘/焦点/热键/Esc 菜单层级强；确认弹窗藏面板（D-C-01）、设置/选项 Esc 缺失（D-C-02/03）、组头误拖（D-C-04）扣分。
- **D 4.5**：零接线失效；死代码与幽灵命名（D-D-01）扣分。
- **E 4.5**：三轮测试基线 + 本轮实测无新功能缺陷。
- **F 3.5**：反馈完整（无「点了没反应」路径——除 D-C-06 的模态禁用场景）；可发现性（D-F-01）与撤销缺口扣分。

- **H 2.5**：UIA 名称覆盖率 6%，行名类型串；对比度与键盘可达达标。

## 7. 修复轮建议排序（供裁定，未实施）

1. **S2 三项**（D-C-01/02/03）—— 一个作用域包装 + 两个 Esc/关闭守卫，工作量小、体感收益最大。
2. **D-H-01 UIA 名称** —— 自动化与可访问性共同受益。
3. **D-G 三组术语 + 英文残句** —— 纯文案，一次过。
4. **D-A/D-B 视觉微调** —— 圆角统一、页脚 14→12、双 accent 按钮。
5. **死代码清理**（D-D-01）—— 独立一次提交，避免与行为修复混淆。
